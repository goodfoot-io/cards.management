# Answer a Follow-Up Question

Verify the question against the task brief, current plan, source, diffs and saved evidence. Research any factual uncertainty. Answer in the conversation with the relevant paths or sources and record the input as processed in `progress.md` and `session.md`.

If the user requested a pause, stop as instructed. Otherwise return to the prior phase. An information-seeking question alone does not discard the active task or authorize additional work.
